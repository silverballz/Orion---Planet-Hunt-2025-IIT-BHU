# Orion---Planet-Hunt-2025-IIT-BHU
ORION is a cutting-edge machine learning system designed to classify asteroids using real NASA datasets. By blending astrophysics-driven feature engineering with powerful classification algorithms, ORION helps identify Near Earth Objects (NEO), Potentially Hazardous Asteroids (PHA), and Non-Hazardous Asteroids (NHA) with high precision.
